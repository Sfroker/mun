# МУН Лаундж — сайт

Одностраничный статический сайт заведения «МУН» (Чебоксары). Тёмная тема,
минимализм, широкоформатная вёрстка с адаптивом под мобильные устройства.
Без сборщиков и зависимостей — открывается как обычный HTML.

## Структура

```
index.html        разметка страницы
css/styles.css     все стили (токены/палитра бренда — в :root)
js/main.js         бургер-меню, модальное окно меню, загрузка меню из Google Таблицы
assets/            favicon и т.п. (логотип и фото — заглушки, см. ниже)
```

## Запуск локально

Любой статический сервер подойдёт, например:

```bash
python3 -m http.server 8080
# затем открыть http://localhost:8080
```

## Подключение меню из Google Таблицы

Кнопка «Меню» открывает модальное окно, которое подтягивает данные из
опубликованного Google Sheet в формате CSV. Пока ссылка не указана —
показываются демо-позиции с пометкой «демонстрационные».

Как подключить реальную таблицу:

1. В Google Таблице: **Файл → Поделиться → Опубликовать в интернете**.
2. Выберите нужный лист и формат **CSV**, нажмите «Опубликовать».
3. Скопируйте ссылку (вида
   `https://docs.google.com/spreadsheets/d/e/2PACX-.../pub?gid=0&single=true&output=csv`).
4. Вставьте её в `js/main.js` в переменную `MENU_SHEET_CSV_URL`.

Формат таблицы — первая строка заголовок, столбцы (порядок не важен,
можно на русском): `category` (категория), `name` (название),
`description` (описание/состав), `price` (цена).

Если ссылка недоступна или таблица пустая — сайт автоматически покажет
демо-меню, чтобы кнопка «Меню» никогда не была пустой.

## Фотографии

Все фото сейчас — плейсхолдеры (блоки с подписью «Фото»), помечены классом
`.ph-block` в `index.html`/`css/styles.css` (секции «О заведении»,
«Атмосфера»). Когда появятся реальные фотографии, замените блоки `<div class="ph-block">…</div>`
на `<img src="assets/....jpg" alt="…">` — стили (радиус, соотношение сторон)
уже настроены под контейнеры.

## Бронирование

Встроено iframe-виджетом Restoza (`https://restoza.ru/book/moon-magic?embed=1`)
в секции «Бронирование». Рядом — прямая ссылка на форму на случай, если
iframe заблокирован браузером/расширениями.

## Карта

В разделе «Контакты» используется встраиваемая Google-карта без API-ключа
(`output=embed`) по адресу «Чебоксары, ул. Толстого, 3». При желании можно
заменить на виджет Яндекс.Карт с точными координатами.
