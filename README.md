# МУН Лаундж — сайт

Одностраничный статический сайт заведения «МУН» (Чебоксары). Тёмная тема,
минимализм, широкоформатная вёрстка с адаптивом под мобильные устройства.
Без сборщиков и зависимостей — открывается как обычный HTML.

## Структура

```
index.html        разметка страницы
css/styles.css     все стили (токены/палитра бренда — в :root)
js/main.js         бургер-меню, модальное окно меню, загрузка меню из Google Таблицы
assets/            favicon и т.п. (логотип и фото — заглушки, см. ниже)
```

## Запуск локально

Любой статический сервер подойдёт, например:

```bash
python3 -m http.server 8080
# затем открыть http://localhost:8080
```

## Подключение меню из Google Таблицы

Кнопка «Меню» открывает модальное окно с переключателем **Кухня / Бар** —
это два раздела одной и той же Google Таблицы («Мун Меню и Карта бара»),
разносить их по разным файлам не нужно. У Google каждый лист публикуется
отдельной CSV-ссылкой, поэтому в коде две константы — по одной на лист.

Пока ссылки не указаны, сайт показывает встроенный снимок реального меню
(`js/menu-data.js`, актуален на 06.08.2026) — так кнопка «Меню» никогда не
бывает пустой, а после публикации таблицы данные начнут обновляться сами.

Как подключить живые данные:

1. В Google Таблице откройте нужный лист снизу (например, «Меню» или
   «Карта бара»).
2. **Файл → Поделиться → Опубликовать в интернете**.
3. В первом выпадающем списке выберите именно этот лист (не «Всю книгу»),
   во втором — формат **CSV**, нажмите «Опубликовать».
4. Скопируйте ссылку (вида
   `https://docs.google.com/spreadsheets/d/e/2PACX-.../pub?gid=123&single=true&output=csv`)
   и вставьте в `js/main.js`:
   - в `MENU_FOOD_CSV_URL` — ссылку листа с меню кухни;
   - в `MENU_BAR_CSV_URL` — ссылку листа с картой бара.
5. Повторите шаги 2–4 для второго листа.

Формат каждого листа — первая строка заголовок, столбцы (порядок не
важен, можно на русском): `category` (категория), `name` (название),
`description` (описание/состав), `price` (цена).

Если ссылка недоступна или лист пустой — сайт автоматически покажет
встроенный снимок для этого раздела, чтобы меню не выглядело пустым.

## Фотографии

Все фото сейчас — плейсхолдеры (блоки с подписью «Фото»), помечены классом
`.ph-block` в `index.html`/`css/styles.css` (секции «О заведении»,
«Атмосфера»). Когда появятся реальные фотографии, замените блоки `<div class="ph-block">…</div>`
на `<img src="assets/....jpg" alt="…">` — стили (радиус, соотношение сторон)
уже настроены под контейнеры.

## Бронирование

Встроено iframe-виджетом Restoza (`https://restoza.ru/book/moon-magic?embed=1`)
в секции «Бронирование». Рядом — прямая ссылка на форму на случай, если
iframe заблокирован браузером/расширениями.

## Карта

В разделе «Контакты» используется встраиваемая Google-карта без API-ключа
(`output=embed`) по адресу «Чебоксары, ул. Толстого, 3». При желании можно
заменить на виджет Яндекс.Карт с точными координатами.
